Read the change,
not just the number.

  • Check the commit, Python build, dependencies, cache state and measured amount of work.
  • A changed workload starts a new baseline. Historical ASV and current results are separate series.
  • Compare CPU estimates, native timings and allocation metrics within their own instruments.
  • Request latency percentiles require request samples; benchmark rounds are not p95 or p99 latency.
